## 6. Stratégie fraîcheur / TTL / pin

- TTL recommandé : **1 h** en mémoire pour `assetShortHeaders/assetPacks/filters`, `assets/{id}.json`, `examples-database/filters`, registres extensions/behaviors.
  Sources : `gb2b …/asset-store.ts` (`CACHE_TTL_MS = 60*60*1000`, `fetchJsonCached`), `…/examples.ts` (idem), `…/cache.ts` (`FRESHNESS_CHECK_TTL_MS = 1h`, `lastFreshnessCheck`, `fetchLatestRef` sur `releases/latest`) ; éditeur sans cache (fetch direct + `retryIfFailed({times:2})`). Déjà acté carte #1 + prototype variante C + `gdevelop-mcp-catalogue-research.md` §5 (registre live + TTL, `status({refresh:true})`, `stale`).
- Pin : tracer par asset `{id, version}` (`Asset.version`, ex. `1.0.0`, `gdevelopVersion 5.0.0-beta100`) + `Last-Modified/ETag` CDN (`assetPacks.json` : `Last-Modified: Thu, 10 Sep 2026`, `ETag`, `Cache-Control: max-age=600` vérifiés) dans chaque réponse search/details **et** chaque import ; refuser ou avertir si `version` a drifté entre details et import (check `getPublicAsset` frais avant apply).
  Attention : le « `packVersion` » de l'issue n'existe pas tel quel au CDN : packs (`starterPacks[]`) n'ont **pas** de version, seuls les assets ont `version`. Voir §7.
- Environnements : `live` seul au MVP (`ApiConfigs.js` `GDevelopAssetCdn.baseUrl{staging,live}`, `GDevelopPublicAssetResourcesStorageStagingBaseUrl`) ; `environment=live` partout (commentaires « keep reading from the live data »).
- Fallback `jsDelivr → raw.githubusercontent` : **uniquement** pour les sources GitHub (`cache.ts` `downloadFile` : `cdn.jsdelivr.net/gh/…` puis `raw.githubusercontent.com`, arbre via `git/trees?recursive=1`, `truncated→erreur`, concurrence bornée) — **pas** pour le CDN assets/exemples (fetch CDN direct, pas de fallback ; cf. `catalogue-research.md` §3.4). - Limites gb2b à ne pas hériter : CDN public seul (pas de premium/privé — assumé hors-scope), scraping wiki (`wiki.ts` : `https://wiki.gdevelop.io`, `extractMainContent` article/main, `htmlToMarkdown` approximatif, `MAX_BYTES=100000`) fragile et hors #18, `gdexporter` beta tiers, mutations JSON à l'aveugle sans moteur (libgd-research §2.1).
